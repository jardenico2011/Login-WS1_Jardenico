# Peace Freedom PHP App

## Run the project

1. Install XAMPP or another PHP server with the `pdo_sqlite` extension enabled.
2. Put this folder inside XAMPP's `htdocs` folder.
3. Start Apache in the XAMPP Control Panel.
4. Open `http://localhost/Login_WS1_Jardenico/index.php` in a browser.

The SQLite database is created automatically in the `data` folder after the first page load.

## Admin account

1. Open `config.php`.
2. Replace `admin@example.com` in `$adminEmails` with your own email address.
3. Register using that email address.
4. Log in. The Admin view button will appear.

There is no demo password. Every account is created from the Register page.
